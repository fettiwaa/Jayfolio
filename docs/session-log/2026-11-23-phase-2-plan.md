## Art direction: "Monochrome editorial"

Keep what makes Jayfolio recognisable and remove what weakens it.

- **Palette:** black, white, and neutral grays only. Every colour comes from a CSS token; no hex values in components. Green, amber, and blue are removed (H5).
- **Hierarchy through type, not decoration:** one named type scale used everywhere.

  | Role | Size | Weight | Used for |
  |---|---|---|---|
  | Display | 4xl → 6xl | bold | hero name only |
  | Page title (`h1`) | 3xl → 4xl | semibold | top of each inner page |
  | Section (`h2`) | 2xl → 3xl | semibold | sections within a page |
  | Sub-section (`h3`) | lg → xl | semibold | cards, entries |
  | Body | base, line-height 1.7 | regular | paragraphs |
  | Small | sm | regular | secondary text |
  | Label | xs mono, uppercase, wide tracking | regular | metadata, dates, stats |

  Subtitles drop from `text-lg/xl` to `text-base/lg` so they no longer compete with headings.
- **Calmer shapes (optional, see D2):** less pill-shaped UI. Cards 0.75rem; buttons and inputs 0.5rem; badges and tech labels 0.375rem. Fully round only where it's semantic: avatar initial, timeline dots, icon buttons.
- **Restrained motion:**
  - Section titles and content groups reveal once; individual items (skill chips, list rows) stop animating one by one.
  - Hover lift is at most 2px.
  - Honours the visitor's reduce-motion setting (H8).
  - Durations 0.3–0.5s, ease-out.
- **Readable contrast:** every text token reaches at least 4.5:1 (H7).

  | Token | Light now → proposed | Dark now → proposed |
  |---|---|---|
  | `--theme-text-secondary` | `#6b7280` (4.47) → `#5f6670` (5.36) | `#8b93a7` (6.24), keep |
  | `--theme-text-muted` | `#9ca3af` (2.35) → `#666b73` (4.96) | `#6b7280` (3.97) → `#80868f` (5.23) |

## What will not change

- Routes, URLs, page set, and nav order.
- All written content, except the corrections above and empty-state wording you approve (6.3).
- The black/white/gray identity, and the dark theme as the default.
- Inter font, 1200px container, Tailwind breakpoints.
- The hero concept: name, tagline, single CTA, player stats, and cycling photo.
- Framer Motion as the animation tool; Jaja as a predefined-answer bot (never described as AI).
- MDX case-study files and their text.
- No new dependencies unless listed under D1.
